# 농지의 QR 생성기

시리얼 번호 목록을 붙여넣으면 QR + 번호 라벨을 A4 한 장에 맞춰 한 번에 만들어 줍니다.
서버 없이 브라우저 안에서만 동작합니다. 외부 API를 호출하지 않고, 인터넷이 끊겨도 쓸 수 있습니다.

## 사용법
1. 시리얼 번호를 한 줄에 하나씩 붙여넣습니다. 엑셀 열을 그대로 복사해도 됩니다.
2. **인쇄용 PDF 받기**를 누르면 A4 한 장에 130개(한 줄 10개 × 13줄, 라벨 간격 3mm, 구분선 없음)가 배치된 PDF가 생성됩니다.
   인쇄할 때 배율은 반드시 **실제 크기(100%)**로 설정하세요.
3. 개별 이미지가 필요하면 **PNG 이미지 묶음(ZIP) 받기**를 누릅니다. 파일명은 `시리얼번호.png`입니다.

## 규격
- 라벨 크기: 가로 1.7cm × 세로 1.9cm (QR 약 1.55cm)
- A4 배치: 상하좌우 여백 5mm, 라벨 사이 간격 3mm(가로·세로 동일), 구분선 없음. 미리보기는 PDF와 같은 배치로 표시됩니다.
- 해상도 600dpi, 오류 정정 레벨 M(15%)

## GitHub Pages 배포 (무료)
1. GitHub에서 새 저장소를 **Public**으로 만듭니다.
2. 이 폴더의 파일을 전부 올립니다: `index.html`, `lib/` 폴더 안의 라이브러리 3개.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**를 누릅니다.
4. 1~2분 후 `https://<아이디>.github.io/<저장소명>/` 주소로 접속합니다.
